# Landing Page Design Skill

## Mission

Design and implement professional SaaS landing pages with coherent art direction, avoiding the "generated by AI" aesthetic. Every page must look like it was produced by an experienced design and engineering team.

---

## Anti-AI Aesthetic

Avoid by default:

- Generic purple/blue gradients
- Glassmorphism
- Decorative blobs
- Excessive glow effects
- Cards with `rounded-2xl` everywhere
- Oversized buttons
- Enormous titles without justification
- Entirely centered interfaces
- Repetitive card grids
- Unnecessary animations
- Generic illustrations
- Sections added only because they are common in SaaS landing pages

The result must feel like a professional designer produced it.

---

## Art Direction

Before building, define:

- **Visual positioning**: What does this brand feel like?
- **Typography**: Primary + secondary typefaces, scale, weight usage
- **Color palette**: Maximum 4-5 colors. Monochrome base + 1 controlled accent preferred
- **Spacing system**: Consistent vertical rhythm
- **Visual density**: How much content per viewport?
- **Shapes**: Sharp corners, subtle radii, or geometric patterns
- **Image treatment**: Photography style, illustration approach
- **Interaction behavior**: Hover states, transitions, scroll behavior
- **Component style**: How do buttons, cards, inputs look?

Art direction must be consistent from first to last section.

---

## Layout Principles

Use intentionally:

- Asymmetry
- Whitespace as a design element
- Vertical rhythm
- Composition variations between sections
- Precise alignment
- Size contrast
- Editorial compositions
- Visually distinct sections

Do NOT turn every section into a card grid.

---

## UX Principles

Every section must have a clear function. Before creating a section, determine:

1. What user question does this section answer?
2. What information must be understood?
3. What action should the user take?
4. Why does this section exist?

Remove sections without clear value.

---

## Conversion Hierarchy

Landing pages must have a clear conversion path:

1. Value proposition
2. Proof / credibility
3. Product understanding
4. Differentiation
5. Objection reduction
6. CTA

Do not artificially repeat the same CTA.

---

## Responsive Design

Mobile must not be a stacked desktop version. Design intentionally for:

- Desktop (1200px+)
- Tablet (768px-1199px)
- Mobile (<768px)

Check for:
- Horizontal overflow
- Typography scaling
- Spacing adjustments
- Navigation behavior
- CTA placement
- Image handling
- Table/chart readability
- Complex section layouts

---

## Accessibility

Respect:

- WCAG 2.1 AA contrast ratios
- Keyboard navigation
- Visible focus states
- Form labels and ARIA attributes
- Semantic HTML structure
- Heading hierarchy (h1 → h2 → h3)
- Alt text for all images
- Accessible button/link patterns
- `prefers-reduced-motion` support

---

## Animation Rules

Animations must be rare and intentional. Use only for:

- User feedback (button press, form validation)
- Page transitions
- Progressive reveal on scroll
- Concept understanding (explaining how something works)
- Enhancing product perception

Avoid:

- Perpetual animations
- Floating elements everywhere
- Unnecessary parallax
- Excessive hover animations
- Elements that move without reason

Always respect `prefers-reduced-motion: reduce`.

---

## Implementation Standards

- TypeScript with strict mode
- No TypeScript errors
- No ESLint errors or warnings
- Responsive at all breakpoints
- Semantic HTML
- Component-based architecture
- Maintainable code structure
- Proper heading hierarchy
- Meta tags for SEO/social
